# ha-yas105 - Home Assistant Yamaha YAS105 Soundbar Control

This repo is for creating the Home Assistant integration for the Yamaha YAS105 Soundbar Control. It is is run as a docker container.

The integration uses Bluetooth Classic device via RFCOMM.
